Import Guidelines
  • Format: Only valid .csv (Comma Separated Values) files are supported.
  • Headers: The first row must contain the exact column headers expected by the system. Do not rename columns.
  • Rate Master: Ensure all RTO strings and Make/Model strings match exactly with the existing master data to prevent validation rejections.
  • Health Rate Master: Columns must match the field names shown on the Health Rate Master page (e.g. insurance_company, product_name, min_sum_insured, payin_rate...). Dates accept DD/MM/YYYY or YYYY-MM-DD; rate columns are plain numbers (33.90, not "33.90%"). Re-uploading the same rule (same insurer/product/category/business type/bands/zone/plan list/dates) updates its rates in place instead of duplicating it.
  • Validation: The system will automatically skip duplicate records based on your defined hash keys.
