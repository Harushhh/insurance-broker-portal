Hardcoded Backend Logic
  • is_cpa

    YES: If uploaded value is a number between 1 and 1000.

    NO: If uploaded value is exactly 0.

    NA: Bypasses restrictions for both YES and NO grids.

  • is_ncb

    YES: If uploaded value is a number between 1 and 99.

    NO: If uploaded value is exactly 0.

    NA: Bypasses restrictions for both YES and NO grids.

  • is_zd

    YES/NO: Exact boolean match (1/0, Y/N, TRUE/FALSE).

    NA: Bypasses restrictions for both YES and NO grids.
